    The C++ behind this site

    This site is the web version of our C++ project, a Movie Rating System. The program stores movies, decides if each one is recommended, and calculates the average rating. Each card below shows one required part of the project, the code for it, and where you can see the same idea on this site.

    Run it with: g++ movie_rating.cpp -o movie_rating, then ./movie_rating
